Roteiro 2
Um projeto simples de lista em kotlin com Jetpack Compose

Sobre:
Esse projeto foi desenvolvido como uma tarefa de aprendizado de lógica Kotlin aplicado ao ecossistema 
do Android Studio com a forma declarativa do Jetpack Compose.

Com ele é possível:
Adicionar e remover elementos de uma lista Kotlin a partir de 2 botões e um campo de texto

Tecnologias utilizadas:
Kotlin
Android Studio
Jetpack Compose

Como executar:
1. Clone o repositório (https://github.com/diegofsilva-sudo/Roteiro2.git)
2. Abra o projeto no Android Studio e aguarde a sincronização das dependências

Código disponível em: https://github.com/diegofsilva-sudo/Roteiro2
